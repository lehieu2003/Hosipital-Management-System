# Cortex Setup

This folder was bootstrapped from `.claude` and adapted for Codex/Cortex use.

Contents:
- `agents/`: role descriptions and ownership guidance
- `commands/`: reusable task playbooks
- `references/`: quick checklists and patterns

Notes:

- Prefer `.cortex/rules` and repository files over copied examples when they conflict.
- Existing linked skills in `.cortex/skills` were preserved; only missing local skills were added.
